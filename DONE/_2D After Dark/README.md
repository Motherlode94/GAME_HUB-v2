# WARLIKE — AFTER DARK

Visual novel 2D Web autonome. Prologue interactif, quatre personnages explicitement adultes, scènes non explicites, choix, affinités, sauvegarde locale.

Le personnage 2D est un portrait stylisé CSS provisoire. Aucun contenu sexuel graphique ni asset externe. Ouvrir via Cloudflare Pages ou HTTP local. Le fonctionnement navigateur n'a pas encore été testé.
