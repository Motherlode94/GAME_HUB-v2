# WARLIKE — REDLINE DISTRICT (First Ignition)
Jeu Web 3D autonome, dans GAME_HUB-v2/DONE. **Pas de moteur WarLike, pas d'Unity.**
## Prototype fourni
- Three.js ES modules (connexion CDN requise)
- Garage : 3 configurations, épreuve circuit / chrono
- Circuit 3D elliptique, conduite arcade clavier ZQSD/WASD, frein à main Espace, repositionnement R
- 5 voitures IA à trajectoire prédéfinie (sans évitement ni collisions encore), 3 tours, chronométrage et record local
- Les véhicules sont des géométries 3D provisoires : **pas encore de véritables modèles GLB**.
