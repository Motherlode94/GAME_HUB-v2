# THE LAST SIGNAL — Chapitre 0 « 02:17 »

Jeu Web 3D autonome (Three.js par CDN), sans Unity ni WarLike Engine.

## Prototype
- FPS clavier/souris, lampe torche.
- Station H-17 explorable (géométrie architecturale temporaire).
- Tableau électrique, radio ajustable 88.0–108.0 MHz, fréquence correcte **97.3 MHz**.
- Porte déverrouillable, présence dynamique rudimentaire, exposition, fin de chapitre.
- À remplacer : vrais modèles GLB, collisions physiques complètes, son spatial et IA de navigation.
