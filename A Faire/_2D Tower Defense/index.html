Tower Defense

Instructions

  • Clique pour demarrer la premiere vague.
  • Bouton "Placer tour" en bas a gauche.
  • Touche C: change le type (Basique / Rapide / Sniper).
  • Shift+clic: multi-selection de tours.
  • Ctrl+clic: selectionne toutes les tours du meme type.
  • U: ameliore la selection, T: re-selection meme type.
  • G: profil IA (magnat, guerrier, scientifique, pacifique, neutre).
  • A: active/desactive l'auto-amelioration IA.
