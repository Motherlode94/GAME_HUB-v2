    Guide rapide / WarLike Gaming

    Défends la base

    1. Construire

    Choisis une défense dans l’arsenal, puis clique sur une case libre. Maintiens Maj pendant le placement pour en poser plusieurs.

    2. Résister

    Déclenche la vague avec Espace. Passe en mode manuel pour choisir quand lancer les renforts.

    3. Améliorer

    Clique sur une tour pour examiner sa portée, changer ses priorités, l’améliorer ou la vendre.

    4. Capacités

    Utilise Z Barrage, X EMP et C Réparation. Les capacités coûtent des crédits et nécessitent un rechargement.
