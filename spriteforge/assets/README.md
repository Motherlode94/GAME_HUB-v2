# Assets SpriteForge

Les fichiers SVG sont trois **assets d’exemple** exploitables dans l’éditeur (héros, ennemi, effet d'énergie). Ils ne remplacent pas les planches PNG originales de Super Hero: Rift City Partie 2.

Pour utiliser les véritables planches, importer le PNG dans SpriteForge puis découper les frames et exporter les PNG. Les SVG peuvent servir à tester l’éditeur. Tous les outils de l’éditeur se trouvent dans `spriteforge/index.html`, avec le chargeur séparé `spriteforge/scripts/asset-loader.js`.
